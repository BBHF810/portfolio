# Haruhiko Takahashi - UI/UX Designer & Design Engineer Portfolio

高橋 治彦（Haruhiko Takahashi）の就活用ポートフォリオサイトです。

## 🌟 概要
- **職種 / 方向性**: UI/UX Designer / Design Engineer / Web Frontend Engineer
- **デザインコンセプト**: Simple & Minimal, Clean & Sophisticated
- **技術スタック**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons

2. **Banquet Record** (`banquet-record`): 宴会タイプ診断＆買い出し自動計算マネージャー (React 19, Vite, React Router, Lucide)
3. **みちのきろく** (`michino`): 自由室みちの 学習記録＆コワーキングスペース予約 (React, TypeScript, Tailwind CSS, Supabase, Gemini API)
4. **きもちパレット** (`feeling`): 感情をカラーとAIで可視化・対話するエモーショナルUI (React 19, TypeScript, Gemini API)
5. **Galactic Splat Kids** (`arata`): 3D Splat Action & インタラクティブ WebGL体験 (React 19, Three.js, React Three Fiber, Tailwind CSS)
6. **AceRank** (`ranking`): 大学バドミントンサークル向け レーティング・ランキングシステム (React 19, TypeScript, Supabase)
7. **Propose** (`propose`): WebRTC P2P リアルタイム対話＆プロポーザルプラットフォーム (Next.js 16, React 19, WebRTC, PeerJS)
8. **ナンバー・レジェンド** (`number_legend`): AI連携・算数知育ゲーミフィケーションWebアプリ (React 19, TypeScript, Gemini API)
9. **Journal App** (`journal_app`): 多言語対応（i18n）・データ永続化 日記管理Webシステム (Python, Flask, SQLAlchemy, Babel)

## 🛠️ ローカルでの起動方法

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動 (http://localhost:5173)
npm run dev

# プロダクションビルド
npm run build

# プレビュー
npm run preview
```

## 📦 デプロイ方法 (Vercel / GitHub Pages)
- **Vercel**: GitHubリポジトリをVercelにインポートするだけで、自動でビルド＆デプロイされます（`vercel.json` 設定済み）。
- **GitHub Pages**: `npm run build` 後、`dist` ディレクトリをホストするか、GitHub Actions ワークフローでデプロイ可能です。
