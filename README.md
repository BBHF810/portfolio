# 高橋 治彦 (Haruhiko Takahashi) — Portfolio

**Human-Centered Design × Software Prototyping**  
人への理解を、使える仕組みに変えるデザインと実装

## 掲載プロジェクト
1. **みちのきろく** (`michino`)
   - 自由室みちの 業務整理・学習記録・予約管理Webアプリ
   - URL: https://michino.vercel.app
   - GitHub: https://github.com/BBHF810/michino
2. **Reflectia** (`journal_app`)
   - 手書き・テキスト対応 AI内省支援ジャーナリングシステム
   - URL: https://journal-app-phi-five.vercel.app
   - GitHub: https://github.com/BBHF810/journal_app
3. **AI相互期待感インタビュー** (`expectation-interview`)
   - 身近な人への「期待」と「実際の出来事」を振り返る対話型Webアプリ
   - URL: https://expectation-interview.vercel.app
   - GitHub: https://github.com/BBHF810/expectation-interview

## ローカル起動方法

```bash
npm install
npm run dev
```
